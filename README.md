# 🧪 Kemi Spil – Folkeskolen 2.-4. klasse

Et interaktivt kemi-spil lavet med **React + Three.js**.

## Sådan kører du det

```bash
cd kemi-spil
npm install
npm run dev
```

Åbn http://localhost:5173 i browseren.

## Funktioner

- **Periodisk system** med danske navne og beskrivelser
- **Drag & vælg** op til 4 stoffer
- **Hæld i reagensglas** med hælde-animation
- **Realistiske (forenklede) reaktioner** baseret på hvad du blander
- **Brænder** med lav / medium / høj blus
- **Sæt brænder under stativet** og se effekter (damp, røg, eksplosion!)
- **Op til 4 reagensglas** fra holder
- **Lærer Kemius** – klik på ? for forklaring af blandingen
- **Dobbeltklik** på et stof for detaljeret forklaring

## Kendte reaktioner (eksempler)

| Blanding | Resultat |
|----------|----------|
| H + O    | Vand (H₂O) |
| Na + Cl  | Bordsalt |
| C + O    | Kuldioxid |
| Mg + O   | Magnesiumoxid (skarpt lys) |
| Fe + O   | Rust |
| Na/K + varme | Eksplosion! |

## Teknologi

- React 18
- Three.js + @react-three/fiber + drei
- Zustand (state)
- Vite

Lavet til undervisning i folkeskolen – sjovt, sikkert og lærerigt!
